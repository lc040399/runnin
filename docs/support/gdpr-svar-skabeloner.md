# Svar-skabeloner: data- og sletningsanmodninger (GDPR)

Genbrugelige svar til mails, der lander på **hello@runnin.org**. Kopiér, tilret navn/detaljer, send fra hello@.

**Kort om reglerne:** svar inden for **1 måned**. Vi gemmer kun e-mail, navn og gemte løb (hos Supabase, EU). Profilbillede + tema ligger kun lokalt på brugerens enhed. Al selvbetjening findes i appen/på web.

---

## 1. Sletning - selvbetjening (send denne først)

> **Emne:** Din anmodning om sletning af data hos Runnin
>
> Hej [Navn],
>
> Tak for din besked - selvfølgelig, det klarer vi.
>
> Du kan slette din konto og alle dine data permanent på under et minut, direkte hvor du bruger Runnin:
>
> - **I appen:** tryk på din profil øverst → **Slet konto** → bekræft.
> - **På web (runnin.org):** åbn dit dashboard → **Profil & indstillinger** → **Slet alt**.
>
> Det fjerner både din konto og dine gemte løb hos os med det samme, og det kan ikke fortrydes.
>
> Vil du hellere have os til at gøre det for dig, så svar bare på denne mail med et "ja", så sletter vi det manuelt og bekræfter, når det er væk.
>
> Rigtig god dag derude,
> Team Runnin
> hello@runnin.org · runnin.org

## 3. Indsigt / download af data

> **Emne:** Indsigt i dine data hos Runnin
>
> Hej [Navn],
>
> Selvfølgelig. Du kan hente en komplet kopi af alle dine data selv:
>
> - **På web (runnin.org):** dashboard → **Profil & indstillinger** → **Download mine data**. Du får en fil med alt, vi har: din konto og dine gemte løb.
>
> For fuld åbenhed er det også præcis det, vi gemmer: din **e-mail**, dit **navn** og dine **gemte løb** - opbevaret sikkert hos Supabase (EU-datacenter). Din adgangskode ser vi aldrig (kun en sikker hash). Profilbillede og temavalg ligger kun lokalt på din egen enhed - dem har vi aldrig.
>
> Kan du ikke få fat i download-knappen, så sig til, så sender jeg udtrækket manuelt.
>
> Bedste hilsner,
> Team Runnin
> hello@runnin.org · runnin.org
